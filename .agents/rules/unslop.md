# Design and Code Craft Standard: Unslop

Apply the unslop craft rules to all user interfaces, components, and frontend code:

## 1. Principles
- **No Vibecoded Tells:** Never use purple/violet glow gradients, glossy glassmorphism blobs, pulsing indicator dots, uppercase tracked labels, emojis as icons, or "✨ New" badges.
- **Quiet Chrome:** Navigation, buttons, inputs, and borders use tinted neutrals and at most one calm accent. Color lives in the data/content moments, not the containers.
- **Editorial Typography:** Clear typographic scale (e.g. Inter / Geist for UI, Geist Mono / JetBrains Mono for codes and tabular numerals). Never mix more than two font families.
- **4px Spacing Grid:** Margins, paddings, gaps, and component heights must align to standard 4px multiples (4, 8, 12, 16, 20, 24, 32, 48).
- **Subtle Depth:** Depth is created via subtle hairlines (`border-neutral-200` / 8-10% opacity) and crisp, neutral micro-shadows—never colored or heavy blur shadows.
- **Concise Copy:** Direct, functional, and honest language. Avoid buzzwords like "supercharge", "magic", "effortless", or "vibe".
